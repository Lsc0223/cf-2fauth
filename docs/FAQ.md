## 安装和部署

### Q: 需要什么前置条件才能部署？

**A:** 你需要：
- Node.js 16 或更高版本
- npm 包管理器
- Cloudflare 账号（免费版即可）
- Wrangler CLI（通过 npm 自动安装）

### Q: 部署到 Cloudflare Workers 需要付费吗？

**A:** 不需要！Cloudflare Workers 的免费计划对个人使用完全足够：
- 每天 100,000 次请求
- 1GB KV 存储
- 无限制的脚本数量

### Q: 安装时遇到 "Authentication error" 怎么办？

**A:** 请按以下步骤操作：
```bash
# 1. 退出登录
npx wrangler logout

# 2. 重新登录
npx wrangler login

# 3. 确认登录状态
npx wrangler whoami
```

### Q: KV 命名空间创建失败怎么办？

**A:** 可能原因：
1. 未登录 Cloudflare - 运行 `npx wrangler login`
2. 账号权限不足 - 确认邮箱已验证
3. 网络问题 - 检查网络连接

### Q: 如何部署到自定义域名？

**A:** 请参考 [DEPLOYMENT.md](../DEPLOYMENT.md) 中的"自定义域名配置"章节。

## 使用问题

### Q: 如何获取 2FA 密钥？

**A:** 通常在网站的 2FA 设置页面：
1. 找到"启用双因素认证"选项
2. 选择"手动输入密钥"或"无法扫描二维码"
3. 复制显示的 Base32 密钥
4. 粘贴到本系统中

### Q: 验证码不正确怎么办？

**A:** 请检查：
1. **时间同步**：确保系统时间准确（TOTP 依赖时间）
2. **密钥格式**：密钥必须是 Base32 格式（大写字母和数字 2-7）
3. **时间周期**：大多数网站使用 30 秒周期，少数使用 60 秒
4. **验证码位数**：通常是 6 位，少数网站使用 8 位

### Q: 可以导入其他 2FA 应用的数据吗？

**A:** 可以！支持：
- **2FAS Authenticator**：导出 JSON 文件后直接导入
- **Google Authenticator**：需要手动重新添加（不支持导出）
- **Authy**：需要手动重新添加（不支持导出）
- **标准格式**：任何符合 TOTP 标准的应用

### Q: 如何备份数据？

**A:** 有两种方式：
1. **本地导出**：点击"导出"按钮，下载 JSON 或加密文件
2. **云端备份**：配置 WebDAV 后，可自动备份到云端

### Q: 忘记备份密码怎么办？

**A:** 很遗憾，备份密码丢失后无法恢复加密文件。建议：
- 使用密码管理器保存备份密码
- 定期创建新备份
- 同时保存加密和非加密备份（注意非加密备份的安全）

### Q: 如何在多设备间同步？

**A:** 使用云端备份功能：
1. 配置 WebDAV（如 Nextcloud、ownCloud）
2. 在一个设备上创建备份
3. 在另一个设备上恢复备份

## 安全相关

### Q: 数据安全吗？

**A:** 是的！安全措施包括：
- **端到端加密**：所有密钥使用 AES-GCM-256 加密
- **HTTPS 传输**：所有通信都通过 HTTPS
- **JWT 会话**：自动过期的安全会话
- **速率限制**：防止暴力攻击
- **无第三方依赖**：减少供应链攻击风险

### Q: Cloudflare 能看到我的数据吗？

**A:** 敏感数据（密钥、密码）都是加密存储的，Cloudflare 只能看到加密后的数据。只要你保管好加密密钥（ENCRYPTION_KEY），数据就是安全的。

### Q: 如果 Worker 被入侵怎么办？

**A:** 即使 Worker 被入侵：
1. 密钥在 KV 中是加密存储的
2. 需要 ENCRYPTION_KEY 才能解密
3. ENCRYPTION_KEY 存储在 Cloudflare Secrets 中，不在代码里

建议：
- 定期轮换密钥
- 启用 Cloudflare Access 限制访问
- 定期审查访问日志

### Q: 可以用于企业环境吗？

**A:** 当前版本更适合个人使用。企业使用建议：
1. 配置 OAuth 登录
2. 启用 Cloudflare Access
3. 实施 IP 白名单
4. 进行安全审计
5. 考虑使用专业的 2FA 管理方案

### Q: 会记录日志吗？

**A:** 系统会记录：
- API 请求（Cloudflare 标准日志）
- 错误信息
- 速率限制事件

不会记录：
- 密钥内容
- 验证码
- 备份密码

## 备份和恢复

### Q: 支持哪些 WebDAV 服务？

**A:** 支持所有标准 WebDAV 服务，包括：
- **Nextcloud** ✅
- **ownCloud** ✅
- **TeraCloud** ✅（10GB 免费）
- **坚果云** ✅
- **Synology NAS** ✅
- **群晖 NAS** ✅
- 其他支持 WebDAV 的服务

### Q: 如何配置 Nextcloud WebDAV？

**A:** 步骤：
1. 登录 Nextcloud
2. 访问 设置 -> 安全 -> 应用专用密码
3. 创建新密码，命名为 "2FA Manager"
4. 在系统中配置：
   - URL: `https://你的域名/remote.php/dav/files/用户名/`
   - 用户名：你的 Nextcloud 用户名
   - 密码：刚创建的应用专用密码

### Q: 备份文件存储在哪里？

**A:** 备份文件按以下结构组织：
```
/2fa-backup/
  └── 年份/
      └── 月份/
          └── 日期/
              └── backup-时间戳.encrypted
```

例如：`/2fa-backup/2024/01/15/backup-1705334400000.encrypted`

### Q: 恢复备份会覆盖现有数据吗？

**A:** 是的！恢复备份会完全覆盖当前所有账户。建议：
1. 恢复前先导出当前数据
2. 或使用"合并导入"功能

### Q: 可以自动备份吗？

**A:** 当前版本需要手动创建备份。计划在未来版本添加自动备份功能。

## 技术问题

### Q: 为什么选择 Cloudflare Workers？

**A:** 优势：
- **无服务器**：无需管理服务器
- **全球部署**：自动分发到全球边缘节点
- **高可用**：Cloudflare 的基础设施
- **免费额度**：个人使用完全免费
- **快速部署**：几秒钟即可部署更新

### Q: 性能如何？

**A:** 非常好！
- **响应时间**：< 50ms（全球平均）
- **并发**：单个 Worker 可处理数千并发
- **扩展性**：自动扩展，无需配置

### Q: KV 存储有什么限制？

**A:** Cloudflare KV 限制：
- **免费版**：
  - 1GB 存储
  - 每天 100,000 次读取
  - 每天 1,000 次写入
- **最终一致性**：全球同步需要约 60 秒

对个人使用完全足够！

### Q: 如何查看日志？

**A:** 实时日志：
```bash
npm run tail
```

或在 Cloudflare Dashboard 查看：
Workers -> 你的 Worker -> Logs

### Q: 如何更新 Worker？

**A:** 非常简单：
```bash
git pull  # 如果使用 Git
npm run deploy
```

更新会在几秒内生效。

### Q: 支持哪些浏览器？

**A:** 支持所有现代浏览器：
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- 移动端浏览器
