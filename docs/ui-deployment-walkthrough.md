## 完整工作流程

### 推荐流程

**阶段一：在 UI 中配置（5-10 分钟）**

1. ✅ 登录 2FA 管理系统
2. ✅ 点击"🚀 部署"按钮
3. ✅ 在"配置"页填写 Cloudflare 凭据
4. ✅ 在"KV 命名空间"页创建两个命名空间
5. ✅ 返回"配置"页填入命名空间 ID 并保存
6. ✅ 在"部署"页生成配置

**阶段二：在本地部署（5 分钟）**

7. ✅ 更新本地项目的 `wrangler.toml`
8. ✅ 在 Cloudflare Dashboard 设置密钥
9. ✅ 运行 `wrangler deploy`
10. ✅ 访问部署的 Worker URL 验证

### 可选步骤

**配置自定义域名**
- 在 Cloudflare Dashboard 绑定自定义域名
- 配置 DNS 记录

**设置 Cloudflare Access**
- 添加访问策略限制访问者
- 配置 IP 白名单

**启用监控**
- 配置告警通知
- 查看使用量统计

## 故障排除

### 常见问题

**Q1: 创建 KV 命名空间失败**
```
错误：❌ 创建失败: API Token 权限不足

解决：
1. 检查 API Token 是否有 KV Storage Edit 权限
2. 重新创建 Token 时选择正确的权限模板
3. 确认 Account ID 正确
```

**Q2: 保存配置失败**
```
错误：❌ 保存失败: 网络错误

解决：
1. 检查网络连接
2. 确认已登录且会话未过期
3. 重新登录应用
```

**Q3: 生成的配置无法使用**
```
错误：部署时提示 KV 命名空间不存在

解决：
1. 确认 KV 命名空间 ID 正确
2. 在 Cloudflare Dashboard 中验证命名空间存在
3. 检查 Account ID 是否匹配
```

## 安全提示

1. **API Token** - 使用密码输入框，避免明文显示
2. **配置存储** - 仅当前用户可访问
3. **HTTPS** - 所有通信使用 HTTPS 加密
4. **会话管理** - 2 小时自动过期
